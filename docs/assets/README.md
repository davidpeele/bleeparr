# Public assets

The icon was generated with the built-in image-generation tool. Final prompt: “Create a flat minimalist square app icon, with a solid dark forest green background, a large cream lowercase b, and five rounded waveform bars inside its bowl: short cream, medium cream, tall warm gold, medium cream, short cream. Large margins, no other text or objects.” Text/provenance metadata was removed on export without altering pixels. The app and README use the same image.

Screenshots are captured from the real built frontend by `scripts/capture_screenshots.mjs` at 1440 and 390 pixels. Every API response is synthetic; external network requests are blocked and mutating API calls are refused. Fictional titles, paths and counts illustrate the interface. `demo-settings.json` contains public installation defaults with empty connection credentials. Screenshots are demonstrations, not performance benchmarks or records of a personal library.
